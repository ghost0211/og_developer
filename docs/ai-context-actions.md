# AI 上下文入口与 Codex 订阅

## 执行计划 AI 解读

在 SQL 编辑器取得执行计划后，点击计划面板右上方的「用 AI 分析」。发送的上下文包括该次计划对应的原 SQL、解析后的计划树、原始 EXPLAIN 结果、内置规则诊断及数据库方言信息。它分析已有计划，不会自动执行 SQL、EXPLAIN ANALYZE 或索引 DDL。

执行计划解读、查询错误修复、历史记录分析和连接信息识别等非聊天入口使用设置中标记为默认的 AI 配置及其默认模型，不使用聊天窗口临时选择的模型。没有标记默认配置时采用配置列表的首项。外部动作不会改写聊天窗口保存的模型选择。

## 默认思考等级与聊天选择

AI 配置中可以设置默认思考等级。聊天输入区的独立「思考等级」按钮提供该模型可识别的推理选项；兼容网关返回能力信息时优先采用服务商信息，可识别的路由模型提供建议选项，未知模型保留手动输入。

- 聊天中选择「配置默认」会清除该模型的临时推理偏好。配置默认等级仅在模型已识别的能力支持它时发送。
- 聊天中显式选择的等级覆盖配置默认等级。
- 聊天中显式选择「提供方默认」表示不发送推理等级参数，让服务商自行决定。
- 兼容网关可能不支持模型家族的所有建议等级；建议来源不等于服务商保证。

## ChatGPT/Codex 订阅账号

此功能是独立的 `OpenAI Codex (ChatGPT)` 提供商，不是 OpenAI API Key，也不是隐藏的 Codex CLI 提供商。它使用账号的 Codex 权益；ChatGPT 订阅与 OpenAI API 余额不是同一计费渠道。

1. 设置 → AI → 新增配置，提供商选择 `OpenAI Codex (ChatGPT)`。
2. 先设置网络代理（如需要），点击「使用 ChatGPT 登录」。
3. 打开 OpenAI 授权页面，输入一次性设备码，登录并授权。需在 ChatGPT 安全设置或工作区权限中启用设备码登录。
4. 授权完成后设置默认模型，点击「应用」保存配置；可用「测试」验证模型访问。
5. 如需非聊天入口使用此账号，把该配置设为默认。

授权期间可以取消；关闭设置页面也会取消仍在进行的授权。访问令牌和刷新令牌只在后端加密保存，前端仅保存不透明的账号关联 ID；调用时刷新令牌并保存轮换结果。订阅凭据只发送至固定的 OpenAI/Codex 服务端点，不允许配置自定义接收地址。

令牌密文与本地密钥分开保存：密文在应用数据库中，密钥文件为数据目录中的 `openai-codex-oauth.key`（Unix 权限 0600；Windows 依赖私有应用数据目录的访问控制，不宣称使用系统钥匙串）。应将整个数据目录及密钥文件视作敏感凭据；仅复制数据库而不复制密钥无法恢复授权，可以重新登录。

桌面版凭据保存在本机后端。Web 版凭据保存在部署服务器，并由该服务的访问控制保护，仅适用于可信私有部署；不要在共享或不可信服务器上登录个人订阅账号。「断开账号」删除本工具保存的凭据，不取消 ChatGPT 订阅；如需撤销上游授权，还应在 OpenAI 账号中操作。

模型目录使用明确固定的 Codex 兼容版本（当前对齐官方 `rust-v0.159.2`），不是 OG Developer 的发布版本。OpenAI 目录含最低客户端版本要求，误传较低版本可能导致目录不完整。设置中的刷新按钮会重新请求目录、绕过后端缓存；后台能力解析可复用 5 分钟缓存。诊断日志 `[ai][codex-models]` 仅包含请求兼容版本、返回模型数与可选模型数，不包含登录令牌或账号标识。

设备码登录与可用模型受 OpenAI 的账号、套餐、工作区和网络政策影响。不保证所有订阅均有相同模型权限。开发测试不使用真实用户账号登录，不读取或导入现有 Codex 登录缓存；最终授权及模型可用性需由账号持有人验证。

认证行为参考：[OpenAI Codex authentication](https://developers.openai.com/codex/auth)。
