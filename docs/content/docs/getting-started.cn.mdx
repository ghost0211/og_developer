OG Developer 是 openGauss 专用数据库开发工具，[dbx](https://github.com/t8y2/dbx)（Apache-2.0）的深度定制 fork。它只专注 openGauss 一种数据库，把方言细节与 PL/SQL 开发体验做透。

本指南带你完成三件事：

1. 安装 OG Developer
2. 创建并测试第一个 openGauss 连接
3. 需要贡献或本地调试时，从源码运行

## 创建第一个连接

<Steps>
  <Step>
    ### 打开新建连接

    从侧边栏或工具栏点击**新建连接**。连接类型选择器只提供 openGauss。

  </Step>
  <Step>
    ### 选择模式

    选 **JDBC**（默认，官方 `org.opengauss.Driver`，完整支持 SHA-256），或 **原生**（wire 协议）。

  </Step>
  <Step>
    ### 填写连接信息

    JDBC 模式填写 URL 如 `jdbc:opengauss://127.0.0.1:5432/postgres` 以及用户名、密码。原生模式填写主机、端口（`5432`）、数据库、用户名和密码。

  </Step>
  <Step>
    ### 测试并保存

    点击**测试**验证凭据、网络和权限。通过后保存连接，从侧边栏打开。

  </Step>
</Steps>

<Callout type="info">如果原生模式报认证失败，服务端很可能在使用 SHA-256（`password_encryption_type=2`）。请改用 JDBC 模式，或在服务端把账号切换为 MD5。详见[连接 openGauss](/cn/docs/opengauss)。</Callout>

## 减少生产环境误操作

- 生产连接用明显的名称（如 `prod-orders`），并用颜色、分组和备注说明用途。
- 只查询场景：数据库只读账号 + **只读连接**标记。
- 对整个连接或指定数据库启用**生产环境保护**，写入需要每次重新明确确认。
- 应用编辑、导入、传输、SQL 文件和 Schema 同步前先审查生成的 SQL。

完整行为和推荐配置见[生产环境与写入安全](/cn/docs/production-safety)。

## 常见连接问题

| 现象 | 排查 |
| --- | --- |
| `password authentication failed` | 服务端使用 SHA-256；改用 JDBC 模式或把账号切为 MD5 |
| 超时 | 主机、端口、防火墙、安全组、VPN 或私有网络 |
| 已连接但没有表 | 默认数据库、Schema、权限或元数据读取权限 |
| 私有网络数据库不可达 | 配置隧道/代理、VPN，或在能到达数据库的机器上运行 |

## 从源码运行

贡献或本地调试 OG Developer 时使用源码模式。

### 环境要求

- [Node.js](https://nodejs.org/) >= 22.13.0
- [pnpm](https://pnpm.io/) 10
- [Rust](https://www.rust-lang.org/tools/install)（stable）
- Make

### 系统依赖

<Tabs groupId="dev-platform" items={["macOS", "Linux", "Windows"]}>
  <Tab value="macOS">通常无需额外系统依赖。</Tab>
  <Tab value="Linux">```bash sudo apt-get install -y libwebkit2gtk-4.1-dev libgtk-3-dev libappindicator3-dev librsvg2-dev patchelf libssl-dev unixodbc-dev ```</Tab>
  <Tab value="Windows">通过 Visual Studio Build Tools 安装 MSVC 工具链；见 [BUILD_WINDOWS.md](https://github.com/ghost0211/og_developer/blob/main/BUILD_WINDOWS.md)。</Tab>
</Tabs>

### 启动开发环境

```bash
git clone https://github.com/ghost0211/og_developer.git
cd og_developer
pnpm install
pnpm dev:tauri
```

`pnpm dev` 只启动前端开发服务器。Web 模式：

```bash
pnpm dev:web
pnpm dev:backend
```

### 构建桌面安装包

```bash
pnpm build
pnpm tauri build
```

安装包输出到 `src-tauri/target/release/bundle/`。

### 测试

```bash
npx vitest run        # 前端测试
cargo test -p ogdeveloper-core --no-default-features \
  --features duckdb-sidecar,mq-admin,sqlite-sqlcipher --lib   # Rust 测试
```

测试实例为本机 Docker 容器（`openGauss-lite` 7.0.0-RC3，端口 5432）；测试库配方见 [Makefile](https://github.com/ghost0211/og_developer/blob/main/Makefile) 中的 `db-*` 目标。
