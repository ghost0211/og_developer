OG Developer is an openGauss-specific database development tool, a deep-customized fork of [dbx](https://github.com/t8y2/dbx) (Apache-2.0). It focuses on one database only — openGauss — with dialect details and PL/SQL development experience done to the extreme.

This guide gets you through three things:

1. Install OG Developer
2. Create and test your first openGauss connection
3. Run OG Developer from source when you want to contribute or debug locally

## Create Your First Connection

<Steps>
  <Step>
    ### Open New Connection

    Click **New Connection** from the sidebar or toolbar. The connection type picker offers openGauss only.

  </Step>
  <Step>
    ### Pick a Mode

    Choose **JDBC** (default) for the official `org.opengauss.Driver` with full SHA-256 support, or **Native** for the wire protocol.

  </Step>
  <Step>
    ### Fill Connection Details

    JDBC mode accepts a URL such as `jdbc:opengauss://127.0.0.1:5432/postgres` plus username and password. Native mode uses host, port (`5432`), database, username and password.

  </Step>
  <Step>
    ### Test And Save

    Click **Test** to verify credentials, network access, and permissions. After the test passes, save the connection and open it from the sidebar.

  </Step>
</Steps>

<Callout type="info">If the native mode reports an authentication failure, the server is likely using SHA-256 (`password_encryption_type=2`). Use JDBC mode, or switch the account to MD5 on the server. See [Connect to openGauss](/en/docs/opengauss) for details.</Callout>

## Reduce Production Mistakes

- Give production connections a distinct name such as `prod-orders`, and use colors, groups, and notes to describe their purpose.
- For query-only access, combine a database read-only account with the **Read-only connection** flag.
- Enable **Production protection** for the whole connection or selected databases; a fresh explicit confirmation is required for writes.
- Review generated SQL before applying edits, imports, transfers, SQL files, or schema sync operations.

See [Production and Write Safety](/en/docs/production-safety) for complete behavior and recommended configurations.

## Common Connection Problems

| Symptom | Check |
| --- | --- |
| `password authentication failed` | Server uses SHA-256; use JDBC mode or switch the account to MD5 |
| Timeout | Host, port, firewall, security group, VPN, or private network access |
| Connected but no tables | Default database, schema, permissions, or metadata read access |
| Private database unreachable | Configure tunnel / proxy, VPN, or run on a machine that can reach the database |

## Run From Source

Use source mode when contributing or debugging OG Developer locally.

### Requirements

- [Node.js](https://nodejs.org/) >= 22.13.0
- [pnpm](https://pnpm.io/) 10
- [Rust](https://www.rust-lang.org/tools/install) (stable)
- Make

### System Dependencies

<Tabs groupId="dev-platform" items={["macOS", "Linux", "Windows"]}>
  <Tab value="macOS">No extra system dependencies are usually needed.</Tab>
  <Tab value="Linux">```bash sudo apt-get install -y libwebkit2gtk-4.1-dev libgtk-3-dev libappindicator3-dev librsvg2-dev patchelf libssl-dev unixodbc-dev ```</Tab>
  <Tab value="Windows">MSVC toolchain via Visual Studio Build Tools; see [BUILD_WINDOWS.md](https://github.com/ghost0211/og_developer/blob/main/BUILD_WINDOWS.md).</Tab>
</Tabs>

### Start Development

```bash
git clone https://github.com/ghost0211/og_developer.git
cd og_developer
pnpm install
pnpm dev:tauri
```

`pnpm dev` starts the frontend dev server only. For the web version:

```bash
pnpm dev:web
pnpm dev:backend
```

### Build Desktop Packages

```bash
pnpm build
pnpm tauri build
```

Desktop installers are written to `src-tauri/target/release/bundle/`.

### Tests

```bash
npx vitest run        # frontend tests
cargo test -p dbx-core --no-default-features \
  --features duckdb-sidecar,mq-admin,sqlite-sqlcipher --lib   # Rust tests
```

A local Docker instance (`openGauss-lite` 7.0.0-RC3, port 5432) is used as the test target; see the `db-*` targets in the [Makefile](https://github.com/ghost0211/og_developer/blob/main/Makefile).
