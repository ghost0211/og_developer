# Crates

Rust crates for DBX live here.

## Directories

- `ogdeveloper-core/` - shared database core, drivers, schema/query logic, import/export, transfer, and plugin support.
- `ogdeveloper-web/` - the Docker/web backend service binary published as `ogdeveloper-web`.

The workspace root is defined in the repository-level `Cargo.toml`.
