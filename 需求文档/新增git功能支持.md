### 一、 核心结论

 完全可行，而且非常实用！

 对于企业级数据库开发，存储过程、函数、包体定义、版本升级脚本（Migration SQL）和测试用例天然需要纳入版本控制。将 Git 深
 度集成到 og developer 中，能让开发者在写完 PL/SQL、重编译后，直接在工具内一键提交或推送到内网 Azure DevOps 仓库，无需
 在终端或外部 Git 客户端（如 TortoiseGit / SourceTree / VS Code）之间反复切换。

### 二、 与当前架构的契合度

 本项目目前已经具备良好的工程基础，接入 Git 成本低、见效快：

1. 已有的 Project（工作区项目）体系：
   
   - 工具内置了 SqlProject（支持绑定本地文件夹作为工作区）；
   - 文件树 ProjectFilesPanel.vue 已支持查看项目目录下的所有 .sql / .ddl 文件并右键执行。

2. 已有的 Diff（差异比对）引擎：
   
   - 代码库中已内置了 DiffLine / 差异高亮组件与 GitDiffScanner（crates/dbx-core/src/sql_parser/git.rs），可直接复用于
     本地改动与 HEAD 版本的 Diff。

3. Azure DevOps / 内网 Git 服务的认证协议：
   
   - Azure DevOps 原生支持 HTTPS + Personal Access Token (PAT) 以及 SSH 密钥，可非常轻量地由后端处理。

   ### 三、 推荐的技术方案架构
   
   ```
   ┌────────────────────────────────────────────────────────────┐
   │                       前端 UI 交互层                         │
   │  - 左/右侧栏「Git 版本控制面板」(分支、改动文件、Commit 输入)  │
   │  - 「从 Git 克隆项目」对话框 (输入 Azure DevOps URL + Token)  │
   │  - 编辑器行号槽与 Diff 面板 (修改前后的行级高亮比对)          │
   └─────────────────────────────┬──────────────────────────────┘
                                │ Tauri IPC / HTTP API
   ┌─────────────────────────────▼──────────────────────────────┐
   │                    Rust 后端 Git 引擎                      │
   │                (crates/dbx-core/src/git.rs)                │
   │  - 基于标准 Git CLI 异步进程执行器 (轻量、跨平台、无编译负担) │
   │  - 支持 HTTPS PAT 认证注入 (安全隔离，支持 Azure DevOps)    │
   │  - 状态嗅探 (git status / log / branch / diff / pull / push)│
   └────────────────────────────────────────────────────────────┘
   ```
   
   #### 为什么推荐「系统 Git CLI 封装」方案？
- 零额外 C 依赖包袱：避免了 libgit2 (C 语言库) 在不同 Linux 发行版或 Windows 上的 OpenSSL / libssh2 编译冲突；

- 原生支持所有内网证书与代理：企业内网自签名 SSL 证书、HTTP 代理、Azure DevOps 凭证助手 (git-credential-manager) 可无
  缝继承系统配置；

- 性能优越：异步进程秒级调用，内存占用极低。

  ### 四、 功能形态与使用场景设计
  
  #### 1. 📥 从 Azure DevOps / 内网 Git 克隆项目 (Clone Repository)

- 交互流程：
  
  - 点击顶部菜单「项目」→「从 Git 仓库克隆...」；
  - 输入 Azure DevOps 仓库地址（如 https://dev.azure.com/company/project/_git/db_repo）；
  - 填入账号或 PAT (Personal Access Token)；
  - 克隆完成后，自动将该目录注册为本地 Workspace 项目，文件树立刻展示所有 SQL 脚本。
  
  #### 2. 🔀 侧边栏「源代码管理 (Git)」面板

- 核心内容：
  
  - 当前分支指示器：如  main /  feature/order_pkg_v2，支持点击下拉一键切换分支或新建本地分支；
  - 云端同步状态：显示与 Azure DevOps 远端分支的领先/落后提交数（如 ↓ 2  ↑ 1），提供一键 「拉取 (Pull)」 与 「推送
    (Push)」；
  - 文件改动清单 (Changes)：
    - 🔴 D (Deleted 删除)
    - 🟡 M (Modified 修改)
    - 🟢 U / A (Untracked / Added 新增)
  - 一键暂存 (Stage / Unstage)；
  - 提交信息输入框 (Commit Message) + Commit（支持快捷键 Ctrl+Enter 提交）。
  
  #### 3. 🔍 代码行级差异比对 (Diff Viewer)

- 在 Git 变动列表中点击任意 .sql 文件，或在右键菜单中选择「查看 Git 差异」：
  
  - 调出 Diff 比对窗口，清晰显示与上一个 Commit 相比新增的绿色行（+）与删除的红色行（-）。
